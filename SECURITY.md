# Security Policy

## Reporting

Do not disclose suspected vulnerabilities, credentials, personal data or exploit details in public issues. Contact the project owners through a private, verified channel.

## Security baseline

- no secrets in source, documentation, examples, logs or evidence bundles;
- least privilege and separate development/production identities;
- explicit trust boundaries and input validation;
- dependency and supply-chain review;
- reproducible or at minimum provenance-bearing release artifacts;
- tested backup and recovery for critical systems;
- independent review for R3 changes;
- documented residual risk and acceptance authority.

## Supported status

This repository is currently a foundation release candidate. Policy documents and templates are supported; no production deployment adapter is yet declared production-ready.

# Support and Maintenance Policy

## Support channels

- operational incidents: use the incident process and private escalation;
- defects or documentation gaps: create a work item;
- policy changes: create a decision record and governed change;
- security concerns: follow `SECURITY.md`.

## Version support

- `current`: actively maintained;
- `supported`: receives security and correctness fixes;
- `maintenance`: critical fixes only;
- `retired`: no new changes;
- `archived`: preserved for evidence and recovery only.

A project must explicitly declare which state applies to each release line.

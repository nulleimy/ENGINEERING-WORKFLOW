# Glossary

- **Adapter:** tool-specific implementation of a portable engineering capability.
- **Baseline:** identifiable starting state with integrity and provenance.
- **Change Set:** bounded collection of changes implementing one work outcome.
- **Evidence:** attributable proof of execution, verification or acceptance.
- **Golden Path:** preferred automated route that makes the safe standard way the easiest way.
- **Project Record:** canonical identity, ownership, state and control profile.
- **Recovery:** rollback, restore or safe-forward return to acceptable service.
- **Work Package:** portable definition and closure record for a unit of work.
- **R0-R3:** increasing risk classes that determine required controls.
- **SLO:** target reliability level for a service-level indicator.

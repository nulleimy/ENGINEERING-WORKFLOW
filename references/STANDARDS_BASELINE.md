# Standards Baseline

This system uses current authoritative sources as reference frameworks, not as claims of certification.

- DORA software delivery performance metrics and continuous improvement: https://dora.dev/guides/dora-metrics/
- NIST SP 800-218, SSDF 1.1 (final): https://csrc.nist.gov/pubs/sp/800/218/final
- NIST SSDF publications, including 1.2 draft and 800-218A: https://csrc.nist.gov/Projects/ssdf/publications
- SLSA specification 1.2: https://slsa.dev/spec/v1.2/
- Diátaxis documentation framework: https://diataxis.fr/
- C4 architecture model: https://c4model.com/
- Backstage Software Templates and golden paths: https://backstage.io/docs/features/software-templates/

## Status policy

- Final standards may define normative baselines.
- Draft standards are tracked and may inform future design but are not silently treated as final.
- Compliance requires a separate scoped assessment and evidence; referencing a standard does not constitute certification.

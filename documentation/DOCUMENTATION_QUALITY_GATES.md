# Documentation Quality Gates

Automate where practical:

- metadata and status validation;
- internal-link validation;
- schema and example validation;
- command/example execution;
- API/reference drift detection;
- diagram compilation;
- terminology and spelling checks;
- ownership and freshness checks;
- prohibited secret or personal-data patterns.

A documentation gate should fail with a specific path, rule and remediation. It must not reward document volume. Quality means correct, discoverable, current and useful.

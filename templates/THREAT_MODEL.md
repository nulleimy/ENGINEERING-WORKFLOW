# Template — Threat Model

## Scope and assets

- system/change boundary;
- users and identities;
- sensitive assets and data classification;
- external dependencies.

## Trust boundaries and data flows

Reference current architecture diagrams.

## Threats

For each threat record actor, precondition, path, impact, likelihood, detection, mitigation, owner and residual risk.

## Abuse and failure cases

Include malicious, accidental, unavailable, corrupted and model-generated failure modes.

## Verification

Security tests, control evidence, monitoring and rollback.

## Acceptance

Named authority, accepted residual risk and review date.

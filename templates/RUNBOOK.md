# Template — Operational Runbook

## Service identity

Owner, environment, current version, dependencies, dashboards and escalation.

## Normal operation

Start, stop, health, readiness, logs, metrics and expected capacity.

## Common failures

For each symptom: diagnosis, safe action, verification and escalation.

## Recovery

Backup location, RPO, RTO, restore steps, validation and last rehearsal.

## Security

Privileged actions, secret handling, audit events and redaction.

## Change history

Runbook changes and review date.

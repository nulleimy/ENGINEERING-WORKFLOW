# Ownership, IP and Provenance Policy

## Product ownership

Collaboration does not automatically transfer ownership of V-One, CyberCore or any other project. Every project declares product ownership, technical stewardship, distribution authority and contribution terms.

## Contributions

Every contribution must have a traceable author and a legitimate origin. Imported code, media, model, dataset or document requires license and provenance review.

## Shared components

A shared component must define:

- owning project or neutral joint ownership;
- license and permitted use;
- maintainers and release authority;
- compatibility policy;
- exit and reuse rights.

## Public repository warning

No license is added by this foundation release. Public visibility does not itself grant reuse rights. A separate explicit licensing decision is required before third-party redistribution or derivative use is authorized.
